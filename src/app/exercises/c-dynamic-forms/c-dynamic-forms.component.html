Learning Goals
  • Show/hide form sections with @if
  • Apply validators conditionally with applyWhen()
  • Exclude hidden fields from validation with hidden()
  • Disable fields conditionally with disabled()
  • Understand: hidden = invisible, disabled = visible but read-only

💡 Part A – applyWhen() 
// applyWhen(root, conditionFn, schemaFn)
// conditionFn receives valueOf — use it to read other fields reactively.
// Angular tracks these reads as dependencies and re-evaluates on change.

applyWhen(
  f,
  ({ valueOf }) => valueOf(f.customerType) === 'business',
  (f) => {
    required(f.companyName);
    required(f.taxId);
    pattern(f.taxId, /^[A-Z]{2}\d{9}$/);
  },
);
💡 Part B – hidden() 
// hidden(field, conditionFn)
// When condition is true → field.hidden() === true → validators are skipped.
// Use field().hidden() in the template to keep visibility in sync with the schema.

hidden(f.address.street, ({ valueOf }) => valueOf(f.deliveryType) !== 'delivery');
hidden(f.address.city,   ({ valueOf }) => valueOf(f.deliveryType) !== 'delivery');
hidden(f.address.zip,    ({ valueOf }) => valueOf(f.deliveryType) !== 'delivery');

// Also add the address validators (they are skipped when hidden):
apply(f.address, addressSchema);

// Template — single source of truth:
@if (!orderForm.address.street().hidden()) {
  <!-- address section -->
}
💡 Part C – disabled() 
// disabled(field, conditionFn)
// When condition is true → field.disabled() === true
//   • The bound input renders with the HTML disabled attribute
//   • Validators on the field are skipped (won't block submission)
//   • The field stays VISIBLE (contrast with hidden())

disabled(f.notes, ({ valueOf }) => !valueOf(f.hasSpecialInstructions));

// Validators added unconditionally — they only fire when NOT disabled:
required(f.notes);
minLength(f.notes, 10);

// Comparison:
//   hidden()   → invisible + validators skipped  → @if (!field().hidden())
//   disabled() → visible but read-only + validators skipped
//   neither    → always visible, always validated
