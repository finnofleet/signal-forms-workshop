signal() · form() · [formField] · schema() · applyEach()

Learning Goals
  • Create a reactive model with signal()
  • Initialize a form with form()
  • Bind inputs with [formField]
  • Read the current value of the form
  • Structure nested objects with schema() and apply()
  • Handle arrays with applyEach()

Part A – Personal Info

[formField] wires an input to a Field in the FieldTree returned by form(). It handles value, change, blur events — no ngModel needed.

Part B – Address schema()

schema() defines a reusable validation block for a specific type. apply() activates it for a nested object inside the form.

Part C – Skills applyEach()

applyEach() registers each array item as its own FieldTree. Without it, array items cannot be individually bound with [formField].

💡 Part A – signal() · form() · [formField] 
protected readonly profileModel = signal({
  firstName: '',
  lastName:  '',
  bio:       '',
});

protected readonly profileForm = form(this.profileModel, (_f) => {});

profileModel()                   // { firstName: 'Ada', ... }
profileForm.firstName().value()  // 'Ada'
💡 Part B – schema() · apply() 
const addressSchema = schema<{ street: string; city: string; country: string; }>((_addr) => {});

protected readonly profileForm = form(this.profileModel, (f) => {
  apply(f.address, addressSchema);
});
💡 Part C – applyEach() · immutable updates 
applyEach(f.skills, (_skill) => {});

addSkill(): void {
  this.profileModel.update(current => ({
    ...current,
    skills: [...current.skills, { id: crypto.randomUUID(), name: '' }],
  }));
}
